# Curtis AI Tech

Local-first AI tooling that lives where your work lives.

Curtis.ai is polyglot AI chat for [Obsidian](https://github.com/curtis-ai-tech/curtis) — 53 providers, agents, skills, MCP, fully local-capable. Around it: a family of tools built on the same principles — plain files, local-first, source-available.

## Open source

| Project | What it does |
|---|---|
| [curtis](https://github.com/curtis-ai-tech/curtis) | Polyglot AI chat for Obsidian — 53 providers, agents, skills, MCP, local-capable |
| [curtis-acp](https://github.com/curtis-ai-tech/curtis-acp) | Curtis as an ACP agent — inside Zed and any ACP client |
| [curtis-ai-audit](https://github.com/curtis-ai-tech/curtis-ai-audit) | Append-only receipts for AI agent activity in your vault |
| [curtis-ai-porter](https://github.com/curtis-ai-tech/curtis-ai-porter) | Port AI chat history (ChatGPT, Claude, Grok, Gemini…) into `.curt` files and Obsidian markdown — and back out |
| [curtis-compliance](https://github.com/curtis-ai-tech/curtis-compliance) | Compliance checks for fintech code — HIPAA / SOC2 / PCI-DSS citations, hash-chained audit trail |
| [curtis-panel](https://github.com/curtis-ai-tech/curtis-panel) | Signal-first desktop control panel |

Docs and landing pages: [curtisai.tech](https://curtisai.tech)
